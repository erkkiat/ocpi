Installing a new instance on Heroku

- Add staging app
- Set HOSTNAME environment variable to full domain name (etc. "abc.ocpiconnector.com")
- Auto deploys on
- Deploy
- Add add-ons: Papertrail, Heroku Redis, JawsDB MySQL or Postgres
- Remove add-on:
- Create superuser
- Check from Papertrail that Celery can reach Redis
  (" heroku/worker.1 Starting process with command `celery --app ocpi22.tasks worker`")
